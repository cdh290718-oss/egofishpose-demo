# 第三组中心两帧：neck 与肩峰自动点实验

只加 neck 与低置信肩峰未解决中心两帧的头部外扩。共同身体自动点误差降低，但手部误差未改善，局部交叉检查变差；本实验不替换默认流程。

## 范围与控制变量

- cam3 19.416 s / cam4 19.407 s，沿用原图、标定与原有神经网络预测缓存。
- 关闭新增头部中心方向/距离限制（guard_enabled=false）。原身体角度先验、全局旋转增量上限、手腕距离、深度和候选筛选规则不变。
- 原始预测与刚体参数逐项一致；shape固定；优化步数、学习率、原接缝算法不变。
- 无人工标注或手工修点，无按帧调参。复用原流程与neck-only对照，本次新跑两帧neck+肩峰完整流程。

四个肩峰均低于原门槛0.3。严格沿用门槛时不新增任何肩峰点，退化为neck-only。因此本次明确为低置信肩峰诊断：新增肩峰门槛为0，坐标仍须有效且在画面内，权重乘score²。原13候选身体点和neck门槛保持0.3。不能称为新增高置信观测。

肩峰采用MoSh++ LSHO/RSHO经其SMPL-H→SMPL-X映射得到的表面顶点4481/6627。来源和映射哈希见landmark_mapping.json，模板核对见template_mapping.jpg。这是解剖表面代理，未证实与Sapiens2标注规范严格一致。neck沿用SMPL-X内部Neck关节代理（原生12，输出7），没有改成C7或其他颈部表面点。

来源：[MoSh++标记表](https://github.com/nghorbani/moshpp/blob/master/src/moshpp/marker_layout/marker_vids.py)、[模型顶点映射](https://github.com/nghorbani/moshpp/blob/master/support_data/smplx_fit2_smplh.npz)。未按这两帧图像手工选择模型顶点。

## 目标函数

每个新增点增加：L = 0.1 × score² × edge_factor × SmoothL1(max(0, d / D − 0.02), beta=0.01)。D为图像对角线，1280×720时容许区约29.37px。edge_factor = clip(距最近边缘的归一化距离 / 0.03, 0.25, 1)。新增三点均为宽松软约束，头部硬几何规则关闭。

辅助损失从身体姿态阶段开始，延续到腕部、轮廓及MANO辅助身体阶段。肩峰经鱼眼投影与表面顶点反传到原身体参数。未将低置信权重归一化成强约束，最终接缝算法保持原样。

## 视觉检查

- cam3_f00001153：身体阶段三方案均出现大幅头部网格外扩，neck+肩峰与neck-only视觉差异很小；最终外扩仍覆盖手部周边。局部投影交叉为左18、右19，原流程左16、右19。
