# session_hand_6：八帧全自动三阶段结果

两段视频各取四帧，时间约 9.7、29.1、48.5、67.9 秒。沿用用户确认的 cam3/cam4 标定。逐帧独立处理，不宣称严格双目同步。

## 三种输出

1. 原始预测：EgoSMPLX snapshot_11，直接使用网络 global_orient / transl，不预先进行 PositionNet、Sapiens2 或人工校正。
2. 身体优化：Sapiens2-1B 自动点；先以 1800 步优化 global_orient、transl，再以 1600 步优化 19 个 body_pose 关节并微调整体姿态。体型、手指参数、面部参数、脚部固定，保留原角度上限、腕部距离及深度约束。
3. 融合：原版 WiLoR 权重产生 MANO 手和二维目标；在新图上自动匹配左右手一次，后续身份固定。身体腕点有界优化，然后比较既有轮廓权重 0.08 / 0.4 的候选；使用可见前臂的分割合并区域约束。将 MANO 按鱼眼像素射线提升到身体腕点深度，并用标准腕环约束和局部谐波位移连接身体与手部。

本次不包含标准 SMPL-X 手指参数拟合的路线 A；第三列直接执行用户要求的 SMPL-X 身体 + MANO 手部路线 B，并保留当前腕点、轮廓和局部表面调整。

## 自动参考误差（像素）

RMSE = sqrt(mean((u_pred-u_auto)^2 + (v_pred-v_auto)^2))。同一帧的三种输出使用完全相同的目标点和身份。身体参考为通过置信度/图内筛选的 Sapiens2 点，手部参考为匹配成功的 WiLoR 21 点。没有人工真值；较小的数值仅说明更贴合自动目标。汇总按全部点合并计算，并非逐帧 RMSE 的算术平均。

## 重载与表面约束

八帧均完成原始/身体参数几何重建，以及最终混合网格独立进程重建与 OBJ/NPZ 一致性检查。体型固定，手臂骨长最大变化小于 1e-5 米。接缝候选保留原有边长比、面积比、法向、腕环半径、深度和手部重投影退化限制；没有合格候选时保留已有网格。数值验收不能替代外形检查。

最终 body_params.npz 只定义标准 SMPL-X 身体基底。混合结果必须读取 hybrid_mesh.npz 或 hybrid_mesh.obj，不能仅凭标准 SMPL-X 参数重建出已融合的 MANO 和局部表面。

旧两阶段脚本只更新其约定的 25 点诊断字段。本次另存 canonical_params.npz 同步可选全关节点字段，参数和网格几何不变；原始脚本产物及验收记录保留。
