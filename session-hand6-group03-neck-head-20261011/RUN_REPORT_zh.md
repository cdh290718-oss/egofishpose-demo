# 第三组邻帧：颈部与头部约束对照实验

- 视觉上，原来大幅外扩的 cam3 19.416 s、cam4 18.409/18.917/19.407 s 都受到明显抑制，效果保留到最终融合阶段。这表明几何限制有效约束了异常解，不等于证明真实三维精度提高。
- 中心两帧仅加 neck 软约束未消除外扩：cam3 仍明显外扩，cam4 改变了外扩方向。该结论只针对本轮代理对应、权重及容差设置。
- 10 帧合并的身体自动点 RMSE 从 18.00 增至 33.12 px；手部从 10.39 增至 10.78 px。新增 neck 未混入身体 RMSE；原有目标点和左右手候选身份保持一致。
- 局部表面交叉检查通过数从 4/10 变为 3/10；cam3 20.409 s 新增右腕 2 对交叉，cam4 20.406 s 左腕交叉从 89 增至 95 对。若干其他帧交叉数下降，但不能把整组记为完整成功。
- 已查看 10 帧身体阶段、最终网格和相同区域的左右手放大图；手指与杯子遮挡附近仍存在贴合差异，未声称所有手指或腕口都正确。
- 颈部自动点集中在图像下沿，不能确认它与 SMPL-X 内部 Neck 的精确解剖对应。相机虽固定在头部，当前没有安装外参；刚体参考自身也在邻帧间波动。
- cam3 中心帧还发现 GPU/CPU 重建的数值差异触发严格头部距离下限和导出回退。网页数值均来自实际保存并重载后的结果，未用优化中的更低残差替代。
- 本次保留为实验分支，暂不替换默认流程。修改前 checkpoint、原输出和关闭新功能的逐项一致性验证均保留。

## 运行范围和可回退性

基于 GitHub EgoSmplx 正式流程 `7ebf5c451762fab2aab391b1274f56bf1829c548`；修改前 checkpoint `7c5ee9ff0a2d870db53e41fec80176d1b79ac0ad`；实验代码 `470ef58045582a0ace4ca00e37628ac9fd8a3229`。原流程默认行为保持关闭新功能，旧输出与原代码工作区保留。

10 张原邻帧采用相同的颈部软约束＋头部几何限制；中心 cam3/cam4 另跑仅颈部软约束，共 12 次完整流程。没有人工标注、修改自动点、按帧调参或人工选择更好看的网格。神经网络预测复用原缓存；从刚体优化到最终融合重新运行，所有原始输入哈希核对通过。原始预测与刚体结果逐项一致，原有身体自动点集合一致。

## 做了什么

1. 原始 EgoSMPLX → 原刚体位置校正保持不变。
2. 从第二阶段身体姿态优化开始，加入 Sapiens neck 的辅助观测。Sapiens channel 69 与 SMPL-X 内部 Neck（native 12 / 输出 7）仅作为不确定代理对应；没有把它当作精确解剖真值。
3. neck 误差在图像对角线 2% 内不惩罚（1280×720 约 29.37 px），超出后采用平滑损失。权重乘置信分数平方与边缘衰减；它不加入原来 13 点 RMSE。
4. 当鼻、双眼、双耳中，少于 3 个点同时满足分数至少 0.7 且位于图内 2% 边界以内，启用头部几何限制。这只是缺少可靠面部观测的启发式条件，不是头部可见性真值。
5. 对 dominant LBS=Head 顶点的质心，相对原刚体结果限制方向变化不超过 8°、相机距离不低于原值 85%。采用软障碍、可行步投影、候选与导出检查。
6. 后续腕点、两种轮廓候选、MANO 辅助身体优化持续应用同样约束；最终仍走原接缝算法。原有形状先验、角度上限、腕距和近裁面限制保持。

cam3/cam4 固定在头部，但用户暂无相机相对头部标定。本实验没有据此编造外参；上述 8°/85% 是统一的实验容差，不是安装测量值。相对原刚体结果的限制可能保留初始错误，必须同时检查身体、手部及表面，不能单凭头部不再入图判定成功。

## 数值与几何限制的边界

cam3 中心帧的诊断复跑捕获到：同一参数在 GPU 与 CPU 重建的最大顶点差约 0.71 mm；头部距离比例从 GPU 的约 0.850000 变为 CPU 的 0.849820，触发严格导出回退。插值路径也不保证位于非凸可行域内。该诊断输出单独保存，未替换正式实验结果或放宽本轮阈值。详情见 export_diagnostic.json。

同一相机的五张邻帧中，刚体拟合的相机到头部质心距离：cam3 约 0.357–0.498 m，cam4 约 0.364–0.472 m。头部质心相对各自均值的三维 RMS 离散分别约 7.57 cm 和 5.09 cm。这些是拟合参考值的变化，不是测得安装位置在变化；模型形状估计也可能变化，不能把它当标定误差真值。它进一步说明逐帧刚体结果不是可靠的实测头戴外参。详见 rigid_reference_variation.json。

当前仍保留原流程所有网格顶点的正深度下限。对于头戴相机，该工程约束与真实头部可能位于相机附近或视野外的情况不一定完全一致；本轮没有更改它，也没有由此推断真实安装外参。

后续值得优先改进的是：统一优化与重建的数值检查并设置有依据的容差；用实际相机安装信息或跨帧共同估计替代不准确的逐帧刚体参考；核查图像边缘的肩/颈点解剖对应。不能通过单纯拉高预测分数或降低自动点 RMSE 证明网格正确。
