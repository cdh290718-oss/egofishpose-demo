# 第三组：第二阶段身体点置信度加权实验

2026-10-11；第三组 cam3 19.415833 s、cam4 19.407352 s。

## 方法与控制变量

- 从原始完整流程 7ebf5c4 开始，不叠加此前跳过第二阶段的改动。
- 保留原有 score >= 0.3、坐标有效且在图内的筛选条件。入选名单和目标坐标完全一致。
- 唯一数值算法改动：第二阶段每点的 Smooth L1 残差（原有宽高归一化，beta=0.003）乘 clip(score,0,1)^2，再除以总权重。
- 保持第二阶段 1600 次、刚体 1800 次、MANO 辅助最大 1400 次及原有早停；先验、步长、角度上限、手腕距离和深度约束不变。
- 原始图片、标定、EgoSMPLX/Sapiens2/WiLoR 缓存保持原样；刚体参数、网格与旧实验逐项完全一致。
- 后续腕点、轮廓、MANO 辅助及原接缝算法代码完全一致。它们的数据驱动阈值、候选及几何会随输入自然变化。
- 网络置信度不是经过标定的正确概率；这次没有标定置信度，也没有消除硬阈值附近的入选跳变。

公式：E = sum_i(w_i * mean_xy(SmoothL1((projection_i-target_i)/[width,height]))) / sum_i(w_i)，w_i=clip(score_i,0,1)^2。

以上 RMSE 均为通常的未加权二维点距离 RMSE，单位 px。两路线使用同一身体点集合和同一 WiLoR 手部候选；不是人工真值或三维误差。JSON 中另附用相同置信度权重评价两路线的加权 RMSE，仅作补充，不与未加权值混比。

- 两张图的身体阶段及最终融合都仍有明显外扩。仅改变自动点权重没有解决该几何问题。
- cam3 的最终身体 RMSE 从 9.04 增至 9.75 px，手部 RMSE 从 9.39 降至 8.97 px。上方网格分布发生变化，但仍覆盖手部附近并向右外扩，不能视作整体修复。
- cam4 的最终身体 RMSE 从 16.62 降至 14.18 px，但最终左侧外扩更明显；手部 RMSE 从 9.28 增至 9.69 px，左侧局部交叉由 0 增至 5 对。更低的身体点误差仍不等于更合理的网格。
- 保留原流程作为默认。新版本仅作为可回退的对照实验，不据这两张图推广到其余帧。

## 权重实际变化

cam3 左踝：原本 10 个点等权，每点 10%；加权后左踝占约 1.87%。cam4 右肩由 12 点等权的约 8.33% 降至约 2.88%。每个点的分数、实际权重与占比见网页表格和 confidence_validation.json。

## 检查与限制

- 两张新结果均通过独立参数与网格重载，但都未通过最终局部交叉检查。交叉数为三角形对数，不是独立缺陷个数。
- 检查范围为局部前臂/接缝与表面，不包含所有共面重叠和全身碰撞。
- 头部入图顶点数只是投影定位指标，不代表可见面积；本例 cam4 数量略降但外扩仍更明显，不能据此单独判定改善。
- 权重实现的三项测试通过：等权退化时损失与梯度匹配原实现；相同残差下高分点影响更大；统一缩放权重不改变损失。
- 本实验仅两张失败样本，不能推断其他场景的总体收益。
