唯一算法改动：在完整流程的身体目标映射中删除 nose。刚体校正、身体姿态、后续腕点/轮廓和 MANO 辅助身体阶段均不使用鼻点。原始预测、自动点文件、手部候选输入、相机标定、先验、迭代次数、约束与优化代码均保持原样。没有叠加置信度加权实验，没有人工标注或单帧调参。
这是整条流程的鼻点消融；刚体初值也会随之变化，不能把差异全部归到第二阶段。原流程对照复用相同版本代码和相同输入的已有结果。

结果观察
  • 两张原本没有同等程度外扩的帧，移除鼻点后均在第二阶段出现大幅头部网格外扩，最终融合仍明显向画面右侧伸出。该对照支持鼻点约束在这两帧中的重要作用。
  • 18.422 s：第二阶段共同非鼻点 RMSE 14.75 → 13.30 px，但鼻点偏差 0.60 → 213.75 px；最终鼻点偏差仍为 225.32 px。
  • 18.927 s：第二阶段共同非鼻点 RMSE 18.55 → 8.76 px，但鼻点偏差 0.77 → 272.04 px；最终鼻点偏差仍为 203.11 px。
  • 删除低分鼻点后，参与点均值反而从 0.616 → 0.632、0.640 → 0.671；平均分提高并未阻止外扩。关键部位约束覆盖不能用均值或点数代替。
  • 两条路线使用相同的 WiLoR 自动匹配候选，最终手部 RMSE 变化较小；手部放大图没有显示能抵消身体外扩的整体改善。
  • 两张新结果均通过独立重载，但局部表面交叉均未通过：18.422 s 左/右 33/15 对，18.927 s 22/0 对。原结果也有局部交叉，不能把原结果称为全部验收通过。
  • 本次从刚体阶段起就在整条流程删除鼻点，因此无法单独归因于第二阶段；也未独立操纵整体置信度，不能据此证明所有低置信度和缺鼻点情形都会失败。默认流程保持原样。
