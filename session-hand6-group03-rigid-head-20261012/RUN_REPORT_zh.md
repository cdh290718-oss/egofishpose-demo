# 第三组中心两帧：刚体头部参考＋原身体点

两帧原先的大幅头部外扩被压住，最终头部相对刚体参考的顶点RMS位移为cam3 4.21mm、cam4 3.09mm。cam3接缝局部交叉明显减少，但共同身体自动点误差和手部整体自动点误差上升，不能视为全部指标改善；保留独立实验，不替换默认流程。

## 原始头部是否固定

核对后端SMPLer_X.py及配置：neutral_face_inference=True，推理时jaw_pose和expression设为零；眼部旋转为零。Neck、Head属于body_pose，仍由网络回归，并非固定值。实际两帧网络/原始/刚体保存的Neck和Head局部旋转一致且非零，两帧数值不同；原身体优化会改变它们。审计、文件哈希和参数见original_head_audit.json。

## 本次方法

使用原来的13候选点及score>=0.3、有限、在图像内的筛选规则。本次中心两帧cam3使用10点、cam4使用12点，共22个观测。没有额外neck、肩峰、胸口等二维自动点，也没有删掉原流程保留的鼻点。

先记录刚体拟合的相机坐标头部网格V0。头部集合H为SMPL-X LBS最大蒙皮权重属于Head原生骨骼15的3345个顶点。固定刚体参考的头部中心c0，定义参考半径平方r0² = mean(||V0_i-c0||²)。新增损失：

L_head = 1.0 × mean(||V_i - V0_i||²) / r0²。

该项约束整个头部表面的相机坐标位移，包含中心和朝向变化；不是仅冻结局部Neck/Head旋转，也不是事后裁掉/替换头部网格。参考完全来自该帧刚体结果，不当作真实头部标定。归一化使用模型自身参考尺寸，不设8°、85%或新硬距离阈值。它是软保持项，不能保证逐顶点严格不动。权重统一1.0，运行前固定，不做逐帧或结果驱动调参。

Neck/Head仍在原19个优化关节中；betas、jaw等原固定参数保持原规则。原身体角度上限、全局旋转增量上限、腕距和深度约束均保留。本次仅增加头部三维保持项；没有引入学习式姿态先验或头部安装标定。

保持项延续到身体、腕部、轮廓、候选选择、MANO辅助身体阶段，原最终局部接缝算法不变。最终选择仍按原自动规则执行；头部参考也参与候选目标打分。
