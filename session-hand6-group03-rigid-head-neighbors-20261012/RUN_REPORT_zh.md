## 方法

沿用原13个候选身体点及其置信度/坐标筛选规则，无新增neck、肩峰等二维自动点。每帧以刚体拟合结果的头部三维表面为参考，Head主蒙皮权重顶点集合H共有3345点。

固定刚体参考V0、中心c0及参考半径平方 r0²=mean(||V0_i-c0||²)，增加 L_head = 1.0 × mean(||V_i-V0_i||²) / r0²。优化使用相机坐标，包含头部位置与朝向影响，不是单纯冻结局部Head/Neck旋转。头部顶点是模型内部三维参考，不是新增自动标注点。

软保持项作用于身体、腕部、轮廓、候选选择和MANO辅助阶段；没有启用旧8°/85%的头部限制。原身体角度上限、全局旋转增量上限、腕距、深度及固定shape规则均保留。
