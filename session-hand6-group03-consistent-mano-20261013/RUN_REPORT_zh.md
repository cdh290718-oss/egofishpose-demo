- D的原始、刚体及身体参数与旧B逐位一致；两帧所有分支使用相同自动目标及手身份。
- 新分支后续根方向、平移及非上肢13个局部关节保持身体阶段值；形状、手部姿态和面部固定。每阶段统一总损失重新评估通过，具体回退记录见delivery_validation.json。
- 新增真实帧CPU/GPU梯度与损失一致性预检查通过，相关8项单元测试通过。原环境存在TF32强制设置，GPU前向与CPU有亚毫米差异；未改变旧环境以免另加实验变量，最终参数均经CPU重建、可行性检查和统一目标复评。新GPU轮廓最近点距离使用直接欧氏距离计算。
- 全部6次新运行完成独立参数重载、拓扑和产物哈希验证；局部交叉另外报告，不能把重载成功等同于网格表面合理。
- 交叉检查为调整前臂/接缝与全表面的非共面三角面配对，排除共享顶点，不包含共面重叠，不是全身无碰撞证明。
- 肩/上臂主要被衣服覆盖，肩部仅弱范围约束；cam4右肩无可靠边界停用。可见轮廓为近似投影外轮廓，无精确遮挡深度缓冲。
- 两帧小样本、单次优化及自动目标误差不足以证明泛化或真实三维精度；统一总损失不增也不保证每项误差均下降。
