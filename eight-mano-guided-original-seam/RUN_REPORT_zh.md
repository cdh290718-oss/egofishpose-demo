## 结果结论

本次未获得稳定的增量提升：同一批自动手点 RMSE 相比原链接 33.00→17.62 px，但相比增强前自动基线 14.91→17.62 px。figure9.2 历史网格为 9.02 px。新增身体约束改善了部分身体点与局部几何，同时导致部分手部投影误差上升；保留实验结果供对比，不整体替换已有基线。

## 身体增强

从原自动腕点/轮廓细化后的身体继续优化。冻结 SMPL-X betas、手指和面部参数，固定骨长及脚关节；优化原 19 个 body_pose 关节、global_orient 和 transl。保留相对原刚体阶段的关节增量上限、整体旋转 8°、平移深度范围、腕部径向距离下限和网格最小深度。
自动目标为 Sapiens2 身体点、WiLoR 腕点、四个非拇指 MCP 掌根点、MANO 腕环 16 个对应像素，以及冻结的可见前臂轮廓采样。MANO 目标直接来自网络投影，不先平移到当前身体腕点。
损失权重沿用选定两帧实验：4×身体 + 4×腕点 + 1×掌根 + 5×腕环 + 1.5×轮廓 + 姿态/平移先验。身体项为置信度加权 Huber(20 px)，另加 0.15 倍平方误差；像素项按 10000 归一化。八帧使用同一配置，未按 figure9.2 调参。
最多 1400 步；连续 200 步最佳目标无超过 1e-7 的改善时停止。身体 RMSE 上界为 min(原 stage2+5 px, 增强前身体+0.5 px)。GPU 迭代后使用 CPU 重新检查，必要时向增强前参数回退。该非凸受约束优化不保证全局最优；停滞和回退比例逐帧保存。

## 原接缝融合

将 MANO 按身体腕点位置和距离放入鱼眼相机坐标系，采用原有腕环和局部平滑过渡，身体与手部在接缝附近共同调整。函数 build() 的语法树已确认与用户选定的 session_hand6 原接缝实现一致。未使用上一轮新的固定 MANO 腕口方案。
保留原边长、面积、法向、腕环尺度、手部投影退化及深度限制。另对结果执行局部非相邻三角形穿插检查；该检查只报告，不悄悄更换用户选定算法。原接缝候选不合格时按原算法保留其基底网格。

## 公平比较与自动参考指标

figure9.2 从已定位的历史原图读取并核对 SHA256；历史参数只在所有自动网格完成独立重建后用于比较，不作为优化输入。历史身体曾使用人工初始化，因此不属于纯自动基线。
历史原图中的手骨架来自 WiLoR 二维点，不能直接当成最终网格精度。本次将历史网格映射回对应顶点后，与所有自动结果统一回归 21 个手部点，再投影并计算误差；同时提供历史网格真实骨架重绘图。
RMSE = sqrt(mean((u_mesh-u_auto)^2+(v_mesh-v_auto)^2))。所有方法对同一批 294 个 WiLoR 自动目标点比较，不是人工真值准确率；汇总按全部点计算。
